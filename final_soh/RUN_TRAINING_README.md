# EV SOH personalized FL training code

## Input
This script expects the output generated by `preprocess_ev_soh_fast_final.py`:

```text
processed_ev_soh/
  client_01.npz
  ...
  client_20.npz
  preprocess_summary.csv
  global_scaler.json
  preprocess_config.json
```

## Recommended run

```bash
python train_ev_soh_pfl.py \
  --data_dir ./processed_ev_soh \
  --out_dir ./training_results \
  --methods centralized,local,fedavg,proposed \
  --session_encoder cnn \
  --hidden_dim 64 \
  --batch_size 64 \
  --central_epochs 25 \
  --local_only_epochs 15 \
  --global_rounds 20 \
  --local_epochs 2 \
  --isolate_methods \
  --method_seed_mode same \
  --trend_weight 0.03 \
  --mse_weight 1.0 \
  --fedavg_best_metric val_rmse \
  --proposed_best_metric val_rmse \
  --personal_ft_epochs 15 \
  --personal_ft_lr 1e-4 \
  --no-personal_ft_freeze_intra \
  --torch_threads 4
```

## Proposed model

- Shared: intra-cycle encoder only. Default is CNN for speed; `--session_encoder gru` is also available.
- Local: FiLM adapter + inter-cycle temporal GRU + heteroscedastic SOH head.
- Loss: heteroscedastic Gaussian NLL + first-version trend consistency loss.
- Aggregation: proposed method aggregates only the shared intra-cycle encoder.
- Checkpointing: FedAvg and proposed use validation-only best-round checkpoints by default.
- Final personalization: proposed can optionally fine-tune each client after loading the best shared encoder; validation-only best personalization checkpoints are used by default.
- Reproducibility: methods are isolated by default. Each method reloads clients/DataLoaders and starts from a deterministic method seed; `--method_seed_mode same` makes proposed-only and full-comparison proposed start from the same seed.
- Merging separate runs: `train_ev_soh_pfl.py` exposes a `merge_results(run_dirs, out_dir)` helper for combining CSV outputs from separately executed method runs.
